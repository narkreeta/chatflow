## Installation

To install and run this application locally, you'll need to have [Node.js](https://nodejs.org/en/download/) installed on your computer. From your command line:

1. Clone this repository
```bash

```

2. Navigate to the project's directory
```bash

```

3. Install project dependencies

4. Start the application
