# ChatFlow

ChatFlow is an AI-powered chat application with a user-friendly interface. The application uses a chat model to generate high-quality responses to user queries in real-time. The interface uses React and Tailwind CSS for a minimal and sleek design.

## Features

1. AI Chat: The chat AI is smart in generating data and is capable of high-level programming to help in development. The AI can provide accurate responses to user queries.

2. Customizable UI: The UI can be easily customized using Tailwind CSS, allowing for a personalized user experience.

3. Real-Time Interaction: User queries are processed and responded to in real time, ensuring a smooth and seamless chat experience.

## File Structure

1. `app/ai.ts`: This file contains the logic for the AI chat model. It processes user queries and provides responses.

2. `app/icon.tsx`: This file defines the icon for the application.

3. `app/layout.tsx`: This file specifies the layout of the application, including the font and metadata.

4. `app/page.tsx`: This file contains the main frontend logic for the application, including the user and AI chat components, and the logic for sending and receiving messages.

5. `tailwind.config.ts`: This file contains the configuration for Tailwind CSS, which is used for styling the application.

## Getting Started

1. Clone the repository
2. Install dependencies using `npm install`
3. Start the application using `npm start`

## Dependencies

1. Next.js
2. React
3. Tailwind CSS
4. AI Chat Model
